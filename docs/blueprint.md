# **App Name**: RiderMaster

## Core Features:

- Live Setlist Architect: Interactive visual editor for managing song sequences with drag-and-drop or arrow-based reordering logic.
- Stage Note Intelligence tool: An AI assistant that analyzes song genres to suggest optimal sound and lighting configurations for each rider entry.
- Unified Postgres Sync: Direct integration with Retool DB/PostgreSQL to perform atomic updates (upsert) for riders and complex song metadata.
- A4 Pro-Landscape Exporter: Dynamic generation of stage-ready PDF documentation in landscape A4 format with specialized layout for technical teams.
- Show Registry Dashboard: A high-level view of all upcoming artists, venues, and dates with one-click navigation to technical specifics.
- Smart Conflict Deletion: Verification flow ensuring data integrity before removing historical riders, complete with an app-wide error boundary.
- Technical Metadata Fieldset: Stylized native date and detail selectors optimized for dark mode efficiency during fast-paced pre-production.

## Style Guidelines:

- Primary color: Stage Gold (#D4AF37) for professional prestige and spotlight warmth.
- Background color: Deep Onyx (#0D0D0D), evoking the atmosphere of a dark stage before the lights go up.
- Accent color: Rust Copper (#B35F37), providing high-contrast cues for warnings and highlights against the gold and black.
- Headline and Body font: 'Space Grotesk' (sans-serif) used in ALL CAPS with extra letter spacing to mirror technical hardware engraving.
- Outlined monochrome icons representing drum silhouettes, rigging cables, and microphones to support the musical stage theme.
- Technical-industrial layout using rigid grids, thick borders, and the RiderMaster v2.0 badge branding.
- SVG background animation simulating rhythmic lighting focus shifts and slow-drifting rigging silhouettes.
